# rekvizit: проверка реквизитов на Swift

Библиотека и консольная утилита, которые проверяют ИНН, ОГРН, ОГРНИП, СНИЛС, КПП, БИК, расчётные и корреспондентские счета и номера карт по контрольным суммам. Ещё она генерирует корректные тестовые номера. Пригодится в форме регистрации контрагента, при импорте списка клиентов и для тестовых данных, когда валидатор на сайте не пропускает «1234567890».

## Пример

Вывод из CI, сборка на Linux:

```
$ rekvizit 7707083893 1027700132195 "112-233-445 95" 044525225
✓ 7707083893  ИНН организации
✓ 1027700132195  ОГРН
✓ 112-233-445 95  СНИЛС
✓ 044525225  БИК
✓ 044525225  КПП

$ rekvizit 7707083894
✗ 7707083894  ИНН организации: не сходится контрольная цифра: ожидалась 3, а стоит 4

$ rekvizit gen inn12 3
590451661886
025452905416
239940111977

$ rekvizit gen счёт 044525225 2
40702810466291185935
40702810642271218811
```

Тип номера определяется по длине и формату. 9 цифр могут оказаться и БИК, и КПП, поэтому утилита показывает оба варианта: номер считается верным, если подходит хотя бы под один.

## Что проверяется

| Реквизит | Правило |
|---|---|
| ИНН организации, 10 цифр | контрольная цифра по весам ФНС 2-4-10-3-5-9-4-6-8 |
| ИНН физлица и ИП, 12 цифр | две контрольные цифры, ошибка указывает, какая не сошлась |
| ОГРН, 13 цифр / ОГРНИП, 15 цифр | остаток от деления первых 12 (14) цифр на 11 (13) |
| СНИЛС | контрольное число по весам 9…1. Номера до 001-001-998 выдавались без него и проходят |
| КПП | формат NNNNPPNNN, причина постановки может быть латинскими буквами |
| БИК | 9 цифр, начинается с 04 |
| Расчётный счёт + БИК | ключ по весам 7-1-3 от последних трёх цифр БИК и 20 цифр счёта. Для счетов в РКЦ ЦБ берётся «0» и 5–6 цифры БИК |
| Корр. счёт + БИК | начинается с 30101, ключ от «0» и 5–6 цифр БИК |
| Номер карты | алгоритм Луна, 13–19 цифр |

Пробелы и дефисы игнорируются: `7707 083 893` и `112-233-445 95` проверяются как есть.

## Установка и запуск

```bash
git clone https://github.com/whysafe/rekvizit && cd rekvizit
swift build -c release
.build/release/rekvizit --help
```

```
rekvizit НОМЕР [НОМЕР ...]           определить тип и проверить
rekvizit счёт СЧЁТ БИК               проверить расчётный счёт вместе с БИК
rekvizit gen ВИД [КОЛИЧЕСТВО]        сгенерировать корректные тестовые номера
rekvizit gen счёт БИК [КОЛИЧЕСТВО]   счёт, который сойдётся с этим БИК
-                                    читать номера из stdin, по одному в строке
```

Код выхода 1, если хотя бы один номер не прошёл проверку. Поэтому файл со списком ИНН можно проверить в скрипте: `rekvizit - < inn.txt`.

## Как библиотека

```swift
// Package.swift
.package(url: "https://github.com/whysafe/rekvizit", branch: "main")

import Rekvizit

switch checkINN(form.inn) {
case .valid: save()
case .invalid(let why): showError("ИНН: \(why)")
}

var gen = Generator(rng: SeededRandom(seed: 42))  // одинаковые номера при каждом запуске тестов
let inn = gen.make(.inn10)
let account = gen.account(for: "044525225")
```

Библиотека не зависит от Foundation, поэтому подключается в iOS, macOS и серверные проекты на Linux без лишнего.

## Как устроено

```
Sources/Rekvizit/Checks.swift     алгоритмы проверки, ошибки с объяснением
Sources/Rekvizit/Detect.swift     определение типа по длине и формату
Sources/Rekvizit/Generate.swift   генератор, SplitMix64 для повторяемых тестов
Sources/RekvizitCLI/main.swift    консольная утилита
```

- **Остаток для ОГРН** считается по цифрам, без перевода номера в число. Поэтому код не зависит от разрядности `Int`: на 32-битных платформах, например на старых Apple Watch, 14 цифр ОГРНИП в него не помещаются.
- **Генератор счетов** подбирает девятую цифру счёта, она служит контрольным ключом. Вес этой позиции равен 3, а 3·k mod 10 перебирает все остатки, поэтому подходящая цифра есть всегда.
- **Сгенерированные номера** правильные только по структуре и не сверяются с реестрами ФНС. Совпадение с настоящей организацией возможно, но случайно.

## Тесты

```bash
swift test
```

13 тестов XCTest:
- настоящие открытые реквизиты ПАО Сбербанк (ИНН, ОГРН, корр. счёт) и классические примеры из документации;
- ошибки с объяснением, крайние случаи контрольного числа СНИЛС;
- определение типа, в том числе неоднозначные 9 цифр;
- 4000 сгенерированных номеров всех видов, каждый проходит проверку;
- изменение любой одной цифры счёта ломает ключ;
- повторяемость генератора с seed.

CI собирает и тестирует проект на Linux (Swift 5.10) и macOS, а также запускает CLI.
